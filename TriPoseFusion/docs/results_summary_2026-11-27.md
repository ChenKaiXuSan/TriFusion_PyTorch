# TriFusion 结果总表（2026-11-27，全部误差为 mm）

现行结果的唯一汇总，取代 `results_summary_2026-08-30.md` 中的自有数据与 Drive&Act 学习型模型数字（那份以米记录、
训练量不统一，保留作历史对照）。过程与决策见 `v3_decision_log_2026-08-30.md` §9–§11。

**单位**：所有误差（MPJPE、PA-MPJPE、分组误差、压力测试）为 **mm**；PCK 为误差在阈值内的关节比例，阈值以 mm 记。
结果 JSON 的字段名仍是 `*_m`（米），汇总脚本输出时 ×1000；关键点坐标文件仍以米存储。

**口径**：输入 = 三视角 SAM3D-Body 关键点（52 关节）逐视角规范化；参考 = 逐序列自标定三角化伪 GT（v3）。
自有数据 88 段、5 折按受试者划分，每段由未见过该受试者的折评测，整段评测。所有学习行同一训练量：
6000 步 × batch 32 × 64 帧窗口，Adam 1e-3，损坏增强 p = 0.5，种子 42，取最后一步（不在验证折上选模型）。
主模型 = 28K SetFusion（d = 32，tag `eqb_setfusion`）。

## 6. 结论

1. **主模型比均值融合好 19.5 mm MPJPE / 3.5 mm PA（−13.1% / −7.9%）**；与 8K、混合版在 MPJPE 上不可区分。
2. **域内精度不是最高**：Temporal-CNN、Lifting-MLP（131–146 万参数）MPJPE 持平，PA 低约 2.5 mm（显著）。加宽主模型不缩小差距。
   在 Drive&Act 域内训练后这一劣势不出现（主模型 21.2 / 19.4，对 22.5 / 20.1 与 22.6 / 19.7）。
3. **置零视角**：所有带损坏增强的学习模型都只退化 2–8 mm，来自增强而非结构；免训练的几何中位数已接近 oracle（152.5 对 152.0）。
4. **加噪视角**：有显式视角权重的模型退化 3–5 mm，无权重的 baseline 退化 10–19 mm（Drive&Act 上 26.0 对 52.8–56.7）。
5. **纯凸加权不提升精度**（148.7 对 148.6），增益全部来自残差修正。
6. **零样本跨机位**：所有带残差的学习模型都劣于均值融合（49.6 / 33.9 对 24.7 / 24.3）；可迁移的是配方，新机位需重训，
   无标注自三角化参考即可（22.3 / 20.8）。
7. 可主张：约 1/50 参数量达到大 baseline 的 MPJPE、噪声视角鲁棒、视角权重可解释、域内重训后最好或并列最好。
   不可主张：自有数据上精度最高；零样本优于均值融合。
